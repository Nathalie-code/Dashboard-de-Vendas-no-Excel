# Dashboard de Vendas no Excel

Projeto de análise de vendas desenvolvido no Excel com uso de tabela dinâmica, gráfico e segmentação de dados.

## 📌 Objetivo

O objetivo deste projeto é analisar o desempenho das vendas por mês, identificar os produtos com melhor desempenho e visualizar a participação das categorias nas vendas.

## 📊 Principais análises

- Total de vendas.
- Quantidade vendida.
- Ticket médio.
- Vendas mensais.
- Ranking dos produtos.
- Percentual de vendas por categoria.

## 🧩 Estrutura do dashboard

O dashboard foi organizado com:
- Cartões com indicadores principais.
- Linha do tempo para filtrar os meses.
- Ranking dos produtos mais vendidos.
- Percentual de vendas por categoria.
- Gráfico de vendas mensais.

## 🛠️ Ferramentas utilizadas

- Microsoft Excel.
- Tabelas dinâmicas.
- Segmentação de dados.
- Linha do tempo.
- Gráficos dinâmicos.

## 📁 Arquivos do projeto

- `sales.xlsx` — arquivo principal com o dashboard.
- `retail_sales_dataset.csv` — base de dados utilizada no projeto.

## 🚀 Como usar

1. Baixe ou abra o arquivo do projeto.
2. Abra o arquivo `.xlsx` no Excel.
3. Use a linha do tempo e os filtros para navegar pelas informações.
4. Analise os indicadores e gráficos do dashboard.
